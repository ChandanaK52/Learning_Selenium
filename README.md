# Learning Selenium — Web Automation with Java

Automation scripts built while upskilling in test automation engineering.

## 🛠️ Tech Stack
- Java
- Selenium WebDriver
- TestNG
- Maven

## 📋 Applications Tested
- MakeMyTrip
- OrangeHRM
- App.VWO.com
- Cura Katalon Demo Site
- Spicejet

## 📁 Project Structure
src/test/java — Test scripts
testNg.xml — Test suite configuration
pom.xml — Maven dependencies

## ▶️ How to Run
1. Clone the repo
2. Open in IntelliJ IDEA
3. Run testNg.xml as TestNG suite
